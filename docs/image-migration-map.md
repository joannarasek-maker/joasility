## Rules from this point forward

For all new content:

1. Create a dedicated folder first.
2. Upload images into that folder.
3. Use lowercase English names with hyphens.
4. Avoid spaces.
5. Avoid Polish characters.
6. Avoid multiple image variants unless necessary.
7. Keep one story = one image folder.
